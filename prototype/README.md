## Что изменилось в v2

Заказчик ответил на первые шесть вопросов — они закрыты, плюс снят вопрос про фотографии.

- **01.** Блог остаётся и называется «Блог». Разделение по читателю, а не по теме:
  статья ловит незнакомого из поиска, карточка Атласа объясняет, заметка удерживает своего
- **02.** Страница локации делится: 14 блоков остаются в доме, 5 уезжают на бренд-уровень,
  4 делятся надвое. У каждого блока в схеме появилась метка `дом` / `регион` / `пополам`
- **03.** Адреса разделов приняты на трёх языках. `atlas` и `blog` не переводятся
- **04.** Переход на бренд-главную запускает второй объект
- **05.** Прочие места — партнёрские. Бронь через нас — отложено
- **06.** «Коллекция» → **«Артефакты»**, адрес `/artefakty`, место в главном меню.
  Не магазин: ни корзины, ни цен сеткой, ни кнопки «купить»
- **08.** Фотографии ушли из блокирующих в очередь: снимаем по списку после того,
  как прототип закрыт целиком. Первый список — 50 кадров по блогу

## Как вернуться к предыдущей версии

```
git checkout prototype-v1
```

Эксперименты ведутся отдельными файлами с другими именами — адреса существующих
схем от этого не меняются.
