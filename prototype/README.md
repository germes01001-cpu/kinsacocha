## Что зафиксировано в этой версии

- Два горизонта: сплошная бирюзовая полоса — строим сейчас, пунктирная серая — заложено на будущее
- Разделы `/dnevnik`, `/atlas`, `/mesta`, `/kollekciya`
- Отзывы заменены на «работаем по рекомендации» плюс гостевая книга от руки
- Вопросы: 7 блокируют, 14 нужны скоро, 14 могут подождать

## Как вернуться сюда

```
git checkout prototype-v1
```

Эксперименты ведутся отдельными файлами с другими именами — адреса существующих
схем от этого не меняются.
