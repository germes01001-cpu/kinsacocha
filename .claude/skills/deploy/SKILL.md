# Выкатка

Сайт статический, Vercel собирает его из ветки `main`. Выкатка — это пуш в `main`.

⚠️ **Наружу уезжает не всё, что в репозитории.** `scripts/sborka.sh` собирает папку
`dist` по белому списку: `index.html`, `img/`, `vid/`, `font/`, `og/kadr.jpg`,
`robots.txt`, `sitemap.xml`, `_headers`. Что там не названо — не уедет. Так и надо:
21 августа выяснилось, что боевой адрес отдавал `CLAUDE.md`, `STATE.md`,
`OPEN_QUESTIONS.md` и всю папку `.claude/` по прямой ссылке. Добавляешь новую папку
на сайт — впиши её в скрипт, иначе её просто не будет.

## Ветки

| Ветка | Что это |
|---|---|
| `main` | боевой сайт, `kinsacocha.vercel.app` |
| `redesign` | рабочая ветка, отсюда сливаем в main |
| `lab` | основная рабочая ветка, отсюда и сливаем в main |
| `stable-2026-08-20` | замороженная копия версии 1.0, не трогать |

Точка отката: тег **`v1.0`**. Вернуться целиком — `git reset --hard v1.0`.

## Порядок

```bash
git add -A && git commit -q -F - <<'MSG'
Заголовок одной строкой, по-русски, без точки

Два-три предложения о том, что изменилось и почему. Не перечислять файлы —
объяснять смысл. Если чинилась ошибка, сказать, в чём она была.
MSG
git checkout main -q && git merge lab -q && git push -q origin main && git checkout lab -q
```

Таймаут на пуш ставить 300000 — сеть отсюда медленная.

## Правила

- **Коммит только после проверки.** Вёрстка — снимком (скилл `shot`), данные — замером
  через `probe.mjs`. Не выкатывать «должно работать».
- **После выкатки дождаться живого сайта и проверить там же.** Условие ожидания
  подбирать по тому, чего раньше не было: `until curl -s ... | grep -q 'новая строка'`.
  Проверка на строку, которая была и до правки, проходит мгновенно и врёт.
- **Заголовок коммита — на русском**, по существу правки. Заказчик читает историю.
- **Один заход — один смысл.** Если правились разные вещи, лучше два коммита.
- В конце сказать заказчику ссылку и что смотреть: `kinsacocha.vercel.app`, какой блок.

## Если что-то сломалось на проде

```bash
git revert HEAD          # отменить последний коммит новым коммитом
git reset --hard v1.0    # вернуть всё к версии 1.0
```

После `reset --hard` пуш в main пойдёт только с `--force-with-lease` — это осознанное
действие, спросить заказчика.
