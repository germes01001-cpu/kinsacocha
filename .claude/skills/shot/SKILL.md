# Посмотреть, что получилось

Правка вёрстки не считается сделанной, пока её не видели глазами. Этот скилл поднимает
локальный сервер, снимает нужный кусок и отдаёт файл, который можно прочитать.

## Как запустить

**1. Сервер** — если ещё не запущен:

```bash
cd /Volumes/DATA/TestVC && python3 -m http.server 8899 >/dev/null 2>&1 &
```

**2. Браузер с отладочным портом** — если ещё не запущен:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --remote-debugging-port=9222 --disable-gpu \
  --user-data-dir=/tmp/kc-chrome about:blank >/dev/null 2>&1 &
```

Проверить, что порт живой: `curl -s localhost:9222/json/version | head -c 80`

**3. Снимок:**

```bash
node .claude/skills/shot/scripts/shot.mjs view экран.png
node .claude/skills/shot/scripts/shot.mjs '.jM' мозаика.png '' 18
node .claude/skills/shot/scripts/shot.mjs view телефон.png '' 10 390
node .claude/skills/shot/scripts/shot.mjs '[data-atlas-preview="zveri"] .jA' звери.png
node .claude/skills/shot/scripts/shot.mjs view глава.png atlas/rasteniya
```

Аргументы: `<селектор|view> <файл> [маршрут] [индекс секции] [ширина]`

**4. Посмотреть** — прочитать полученный png. Не пропускать этот шаг: файл создаётся
даже когда на странице пусто.

## Проверить состояние страницы

```bash
node .claude/skills/shot/scripts/probe.mjs "JSON.stringify({y:scrollY,cls:document.body.className})"
```

Годится, чтобы убедиться, что фон встал, класс переключился, цена подставилась.

## Что этот браузер врёт

Проверено дорого, повторять не надо:

- ~~Мобильная раскладка считается неправильно.~~ **Проверено заново 20 августа 2026:
  это неверно.** При `Emulation.setDeviceMetricsOverride` с `mobile:true` и
  `deviceScaleFactor:2` медиазапросы срабатывают как положено: на 375 px гамбургер
  показан, меню свёрнуто, лифт скрыт. Мобильную вёрстку можно и нужно смотреть здесь,
  а не перекладывать на заказчика.
- **Вкладка всегда `hidden`.** Поэтому не идут кадры анимации: `requestAnimationFrame`
  молчит, `scrollTo({behavior:"smooth"})` не двигает страницу. Если проверяется прокрутка —
  смотреть на итог, а не на анимацию.
- **Кадр может быть устаревшим.** Скрипт делает микро-толчок прокрутки перед снимком,
  но если картинка противоречит замеру через `probe.mjs` — верить замеру.
- **Ленивая загрузка.** Кадры вне экрана не подгружены и выйдут пустыми плитками.
  Прокрутить к нужной секции четвёртым аргументом.
