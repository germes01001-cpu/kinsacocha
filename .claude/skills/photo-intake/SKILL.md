# Приёмка фотографий

Заказчик кладёт кадры из Lightroom в `ВХОД/<папка блока>/`. Оригиналы в репозиторий
не идут — в `img/` попадают только сжатые webp.

## Порядок

**1. Посмотреть, что появилось**

```bash
cd /Volumes/DATA/TestVC/ВХОД && for d in */; do
  n=$(ls -1 "$d" 2>/dev/null | grep -v '^\.' | grep -v 'Снимок' | wc -l | tr -d ' ')
  [ "$n" -gt 0 ] && printf '%-34s %s\n' "$d" "$n"; done
```

Пропорции каждого кадра — это главное, от них зависит, в какой слот он встанет:

```bash
for f in *.jpg; do echo "$(sips -g pixelWidth -g pixelHeight "$f" | grep -o '[0-9]*$' | tr '\n' ':')  $f"; done
```

**2. Разложить по слотам.** Заказчик режет кадры под сетку сам, и обычно набор сходится
один в один: один вертикальный, два широких, четыре квадратных — ровно столько слотов
в витрине Атласа (`A_PATTERN` = big 3:4, wide 16:9, sm 1:1, sm, wide, sm, sm).

**Пропорция важнее присланного порядка.** Если заказчик перечислил кадры в порядке, где
широкий попадает в квадратный слот, — поменять местами и сказать об этом. Резать широкий
кадр в квадрат нельзя.

Если кадры разных форматов и под сетку не ложатся — мозаика колонками, класс `jM`:
каждый кадр стоит в своей пропорции целиком.

**3. Сжать.** Имя файла — первые 12 знаков md5 от пути, так кадр не задваивается:

```bash
conv() { local f="$1" w="$2"; local h=$(printf '%s' "$f" | md5 -q | cut -c1-12)
  cwebp -quiet -metadata none -resize "$w" 0 -q 56 "$f" -o "img/$h.webp" && echo "$h $(basename "$f")"; }
```

Ширина по назначению: вертикальные 900–1000, широкие 1400, квадраты 1100,
фон во всю ширину 1600, мелкие плитки 700. Качество 54–60; если файл вышел
больше 300 КБ — пересжать уже.

`-metadata none` обязателен: в оригиналах есть GPS-метки, а весь сайт стоит на том,
что мы не публикуем координаты.

**4. Поставить в разметку.** Заглушка выглядит так:

```html
<div class="ph r43 sc-house noise"><span>Типи изнутри — кадра нет</span></div>
```

Кадр — так:

```html
<div class="ph r43 sc-house" data-shot data-bg="img/9b7d133812d4.webp"
     style="background-size:cover;background-position:center"></div>
```

⚠️ **`.webp` в `data-bg` обязателен.** Без расширения ленивый загрузчик молча снимает
атрибут, а фон не ставит: плитка остаётся пустой и в консоли ничего нет. На этом
уже терялся час.

Класс пропорции менять под кадр, а не наоборот: `r34` 3:4, `r43` 4:3, `r11` квадрат,
`r169` 16:9, `r219` 21:9, `r45` 4:5.

**5. Проверить снимком** — скилл `shot`. Обязательно: путь может быть верным,
а кадр не тем.

**6. Обновить учёт** — строку блока в `ВХОД/КАК_КЛАСТЬ.md` (✅/⏳) и, если закрылась
крупная дыра, `NEXT.md`.

**7. Выкатить** — скилл `deploy`.

## Что сказать заказчику

- Что встало и куда, коротко
- Что осталось заглушкой в этом блоке
- Если кадр не подошёл по смыслу — сказать прямо, а не молча поставить

## Требования к исходникам

3000 px по длинной стороне, JPEG q85, sRGB. Меньше 2000 px не годится.
Дополнительно жать не нужно — это моя работа: кадр 4 МБ становится 50–250 КБ.
